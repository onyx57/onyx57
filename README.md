### How I think about QA

- Verify outcomes, not actions. A green test that didn't actually
  exercise the feature is worse than a red one.
- 30 seconds before calling something a failure. Latency is not a bug.
- No try/catch in test bodies. If a step can fail, the test should fail loudly.
- Tests that share state share bugs. Parameterize, isolate, repeat.
- The bug you can't reproduce is the bug that pages someone at 2am.
